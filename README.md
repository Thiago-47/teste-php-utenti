# Prova Tecnica - Gestione Utenti (PHP + PostgreSQL)

Progetto sviluppato da **Thiago Abreu** per la prova tecnica.

## 🚀 Tecnologie Utilizzate
- **PHP 8.x**
- **PostgreSQL**
- **HTML5 / CSS3 / JavaScript (Vanilla)**

## 🛠️ Come Eseguire il Progetto

1. **Configurare il Database:**
   - Importare il file `database.sql` nel proprio server PostgreSQL per creare la tabella `utenti`.

2. **Configurare la Connessione:**
   - Aggiornare le credenziali nel file `db.php` se necessario (host, dbname, user, password).

3. **Avviare il Server:**
   - Eseguire il comando nella cartella del progetto:
     ```bash
     php -S localhost:8000
     ```
   - Aprire il browser su `http://localhost:8000`
